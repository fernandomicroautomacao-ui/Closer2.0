  • Molde de Economia de Espaço (Link de Template Externo): Em vez de armazenar milhares de linhas de HTML/CSS pesado no banco, cadastre apenas a URL do template externo (ex: seu site Schmalz/MiCRO no ChatGPT ou servidor próprio). 🪟 Como rodar no Windows (Prompt de Comando ou PowerShell):

1. Certifique-se de ter o Node.js instalado (nodejs.org).
2. Abra o Prompt de Comando (CMD) ou PowerShell como Administrador e execute:

npx @open-wa/wa-automate -p 8080 --popup
Uma janela do navegador (Google Chrome) abrirá exibindo o QR Code. Escaneie-o com o WhatsApp no celular ("Aparelhos conectados"). Pronto! A API ficará ativa em http://localhost:8080.
